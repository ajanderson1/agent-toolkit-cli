# MCP Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement `agent-toolkit-cli mcp import <file>` to reconstruct the MCP library from an exported `mcps-library.json`.

**Prerequisite:** #481 (`mcps-library.json` manifest) is completed.

## Global Constraints

- Never mutate `mcps-lock.json`.
- Commit the manifest first, then materialize.
- Never crash on a single server materialisation failure (partial success). Return exit code 1 if any failure occurs.
- Redact secrets in diagnostics.
- Ensure `--local` is rejected correctly.
- Print parity notes similar to `skill import`.

### Task 1: Create the basic import command and registration

**Files:**
- Create `src/agent_toolkit_cli/commands/mcp/import_cmd.py`
- Modify `src/agent_toolkit_cli/commands/mcp/__init__.py`

**Implementation:**
- Create a click command `@click.command("import")` taking a `file` argument (Path) and a `--latest` flag.
- Register it in `__init__.py` as `import_cmd`.
- Basic input validation:
  - If `not file.exists()`, `raise click.UsageError`.
  - If `file.name == "mcps-lock.json"`, `raise click.ClickException` explaining that `mcps-lock.json` contains no authoring spec and `mcps-library.json` must be used.
- Call `read_manifest(file)` to load incoming entries. Handle `ValueError` or `json.JSONDecodeError` with a friendly ClickException.

- [ ] Implement command structure and registration.
- [ ] Pass the tests.

### Task 2: Implement the core import loop and skip logic

**Files:**
- Modify `src/agent_toolkit_cli/commands/mcp/import_cmd.py`

**Implementation:**
- Read the current manifest (`read_manifest`) and physical library (`scan_entry_files`).
- Initialize `added`, `skipped`, `failed` lists.
- Sort incoming slugs. For each incoming entry:
  - Check existence in current manifest or physical library -> skip if present.
  - Check `install_method == "local"` -> hard skip.
  - Call `assert_safe_entry(entry)` -> on `UnsafeMcpSpecError`, catch it, redact error (which the exception already does), and skip.
- Output formatting matches `skill import`.

- [ ] Write tests for:
  - Skip already existing (manifest or physical).
  - Skip `--local` entries.
  - Skip unsafe entries (quarantine).
- [ ] Implement skip logic.
- [ ] Pass the tests.

### Task 3: Implement `--latest` resolution and atomic persistence

**Files:**
- Modify `src/agent_toolkit_cli/commands/mcp/import_cmd.py`

**Implementation:**
- For each entry that passes skip logic:
  - If `--latest`, use `_reresolve(entry, slug)` from `update_cmd.py` to get a fresh version.
  - Copy the entry into the current manifest dictionary.
  - Call `write_manifest`.
  - Call `materialize_entry(library, entry, overwrite=False)`.
  - If `materialize_entry` or `_reresolve` throws an error, append to `failed`, print a failure line, and continue to the next.
- After the loop, print summary and parity `_NOTES`.
- Exit with code 1 if `failed` is not empty.

- [ ] Write tests for:
  - Successful import of a new entry (both config and sidecar materialize).
  - `--latest` flag updating an incoming pinned npx spec.
  - Partial failure (e.g. sidecar write fails) leaving the loop to continue to next and returning exit code 1.
  - The loop properly writes manifest iteratively (a crash mid-way retains previously imported).
- [ ] Implement `--latest` and persistence.
- [ ] Pass the tests.
